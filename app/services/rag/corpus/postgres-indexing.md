# PostgreSQL: индексы, MVCC и EXPLAIN

B-tree — индекс по умолчанию, подходит для равенства и диапазонов (`=`, `<`, `>`,
`BETWEEN`, `ORDER BY`). GIN используется для составных значений (jsonb, массивы,
полнотекстовый поиск), GiST — для геометрии и нечётких/диапазонных типов.

Индекс ускоряет чтение, но замедляет запись и занимает место, поэтому индексируют
колонки из условий WHERE/JOIN/ORDER BY, а не всё подряд. Частичные и составные
индексы помогают под конкретные запросы; порядок колонок в составном индексе важен.

MVCC (multiversion concurrency control): каждая транзакция видит снимок данных, а
обновления создают новые версии строк вместо блокировки на чтение. Поэтому чтение
не блокирует запись и наоборот. Старые версии убирает `VACUUM`/autovacuum.

`EXPLAIN ANALYZE` показывает реальный план выполнения и тайминги. Признаки
проблем: `Seq Scan` по большой таблице там, где ожидался индекс; сильное
расхождение между estimated и actual rows (устаревшая статистика — поможет
`ANALYZE`). Уровни изоляции: Read Committed (по умолчанию), Repeatable Read,
Serializable.
