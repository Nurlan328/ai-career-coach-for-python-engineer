# Async / asyncio и event loop

Event loop — это цикл, который управляет выполнением корутин: запускает их,
приостанавливает на `await` и возобновляет, когда готов результат. В каждый
момент в одном потоке выполняется одна корутина — конкурентность достигается за
счёт переключения на точках ожидания, а не за счёт параллелизма.

`async def` объявляет корутину; вызов возвращает объект корутины, который должен
быть выполнен в event loop (через `await`, `asyncio.run`, `create_task`).

`asyncio.gather(*aws)` запускает несколько awaitable конкурентно и ждёт все
результаты. `asyncio.create_task(coro)` планирует корутину в фоне и сразу
возвращает Task, не дожидаясь завершения.

Главная ошибка — блокирующий вызов внутри async-кода (`time.sleep`, тяжёлый CPU,
синхронный запрос к БД). Он блокирует весь event loop, и все остальные корутины
встают. Решение: использовать асинхронные библиотеки, либо выносить блокирующий
код в пул потоков через `asyncio.to_thread(...)` или `run_in_executor`.
